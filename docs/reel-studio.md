# 릴스 만들기 (업로드 툴 '릴스 만들기' 탭)

원본 영상 → 9:16(1080×1920) 맞추기 · 맨티스 로고 · 한국어 자막 · 원작자 크레딧 → 완성본(`reel.mp4`, 95MB 이하)을 바로 예약.
비용 0원 (GitHub Actions + Whisper 받아쓰기 + DeepL 무료 Developer 플랜: 처음 한 번 100만 자, 릴스 약 2,000개 분량).

**권리가 있는 영상만** 넣는다: 직접 촬영, 상업 이용 되는 무료 스톡, 원작자에게 허락받은 영상.
남의 릴스를 주소로 내려받는 기능은 일부러 넣지 않았다.
11/6 회의에서 "해외·틱톡 레퍼런스를 우리 걸로" 얘기가 나왔지만 이 원칙은 그대로: 허락 없는 남의 영상은 내려받거나 다시 올리지 않고, 직촬·스톡·허락받은 영상 안에서만 자동화한다.

**직촬 기준 (C 촬영용)**: 얼굴·목소리·손 출연 없음. 1층 같은 장소에서 제품 플랫레이·제형 클로즈업 위주 (맨티스는 정체를 드러내지 않는다).

## 스타일 3개 (레퍼런스 보드 그룹 기준)
| 스타일 | 화면 | 자막 | 소리 | 크레딧 |
|---|---|---|---|---|
| 해외 소스 · 세르칸 (보드 A+S) | 위쪽 훅 문구 고정 + 로고 + 아래 자막 (원본 영어 자막은 가리지 않고 한국어 자막을 그 밑에) | 영어 → 한국어 번역 | 원본 | 필수 (영상 + 캡션) |
| B 포맷 | 위쪽 흰 제목 띠 + 장면마다 바뀌는 #1 #2 #3 단계 문구 | 직접 쓰기 (말이 있으면 받아쓰기도 가능) | 배경음 | 없음 |
| C 촬영용 | 로고 + 자막만 | 받아쓰기 또는 직접 쓰기 | 원본 / 소리 없이 자막만 / 따로 녹음한 음성 | 없음 |

- 자막은 **항상 한 줄**. 받아쓰기 때 긴 문장은 자동으로 나눠 두고, 편집기에서 ✂(글자 칸에서 클릭한 곳에서 나누기, 아니면 가운데)·⤵(다음 자막과 합치기)·글자·시간을 직접 고친다. 잘못 고쳤으면 Ctrl+Z (되돌리기) / Ctrl+Y (다시 하기).
- 위쪽 문구(훅·제목)·단계 문구는 Enter 로 넣은 줄바꿈만 반영 (자동 줄바꿈 없음).
- 위쪽 문구 칸 아래에 **추천** 칩 (작업 이름·자막의 주제와 숫자로 만든 몇 가지 말투, 규칙 기반). 누르면 들어가고 직접 고친다.
- **글자 스타일**: 위쪽 문구·자막·단계 문구·출처 각각 글꼴(프리텐다드·프리텐다드 굵게·블랙한산스·도현·주아·나눔명조)·크기·위치·글자색·강조색·테두리·배경 박스를 고른다. 로고는 버전(심볼+MENTIS / MENTIS 글자만 / 심볼만 / 심볼 옆에 MENTIS)·보이기·색·크기·위치(맨 아래까지)·진하기·굵기(0~4, 기본 2).
  **'지금 설정을 기본값으로'** (자막 화면·썸네일 화면 둘 다 있음) → 자막·위쪽 문구·출처·로고 스타일 + 썸네일(디자인·멘트 글자·로고)을 `templates/reel-presets.json` 에 스타일별로 저장, 다음 작업부터 그대로 시작.
- 코너 이름(스킨케어 노트 등)은 **썸네일에만** 들어가고 릴스 화면에는 안 나온다.
- 출처(크레딧): '영상 안에 출처 표시' 체크로 켜고 끈다. 꺼도 해외 소스는 캡션 끝 출처 줄과 허락 확인은 그대로.
- `*별표*` 로 감싼 말은 강조색.
- 기본값은 `templates/reel-styles.json` (1080×1920 기준 px), 글꼴 파일은 `assets/fonts/` (모두 무료 OFL·Pretendard 라이선스).
- 로고: `assets/logo.png` (투명 배경 PNG) 가 있으면 그 이미지, 없으면 글자 'Mentis'.

## 썸네일 (릴스 만들기 작업 화면 맨 아래)
- **장면**: 영상에서 선명하고 너무 어둡거나 밝지 않은 장면을 서로 떨어진 곳에서 3개 추천. 막대로 직접 골라도 된다.
- **멘트**: 위쪽 문구·자막에서 주제·숫자를 뽑아 3가지 추천 (규칙 기반, AI 아님). 눌러서 넣고 직접 고친다. Enter 줄바꿈, `*강조*`.
  영상 주제와 맞는 멘트가 먼저다 (11/6 회의의 대상 좁히기 규칙은 억지스러워서 자동 추천에는 넣지 않음).
- **디자인**: 매거진(아래 명조체 + 금색 선) / 볼드(가운데 블랙한산스) / 박스(흰 박스) / 미니멀(위쪽 굵은 고딕). 글자 크기·위치, 사진 어둡게.
- **멘트 글자**: 글꼴·글자색·강조색·테두리 색과 두께 (바꾼 값은 디자인을 바꿔도 유지, '디자인 기본으로'로 되돌림).
- **MENTIS 로고**: 버전(심볼+MENTIS / MENTIS만 / 심볼만 / 심볼 옆에 MENTIS)·색·크기·위치(디자인 기본/위/아래/없음). 좌우·위아래 슬라이더나 썸네일 위에서 로고를 끌어 원하는 자리로 옮길 수 있다.
- **썸네일 저장** → `studio/작업/cover.jpg` (+ `thumb.json` 설정). 예약하면 `queue/…/cover.jpg` 로 같이 옮겨지고,
  인스타 릴스 발행 때 `cover_url` 로 커버가 된다. 네이버·샤오홍슈 outbox 에도 `cover.jpg` 가 같이 들어간다 (어사이드 루틴은 아직 표지 설정 안 함).
- 유튜브 쇼츠·틱톡은 API 로 표지를 못 바꿔서 앱에서 직접. '내려받기'로 jpg 를 받아 쓸 수 있다.
- 브라우저 캔버스로 그려서 미리보기 = 저장되는 그림.

## 세딸 자동 제작 (탭 위쪽 '세딸 자동 제작')
허락받은 영상 여러 개를 **영상함**에 넣으면 (원작자 계정·허락 메모는 영상마다) → 자막 만들기 → **Claude 예약 작업**(매일 밤 11시, 지시문 `docs/reel-auto-routine.md`)이
자막 다듬기·훅 2개·위치/색 맞추기·썸네일 설정·캡션을 만들고 다른 Claude 가 채점(조회 40·공유 30·저장 30) → `reel-auto.yml` 이 완성본 →
**후보**에 점수 순으로 뜬다. '올리기' = 썸네일(cover.jpg)을 그리고 캡션이 채워진 예약 화면으로 (날짜 고르고 예약하기, 세딸). '열어서 고치기'로 평소 편집 화면.
자동 제작은 출처를 화면에 넣지 않고 캡션 끝 줄에만 쓴다. 설계: `docs/reel-auto-design.md`.
**완성본에서 배우기**: 릴스를 예약하면 만든 설정(자막·스타일·썸네일·Claude 초안)이 `queue/…/reel-make/` 에 같이 남는다 (발행 뒤엔 `published/…/reel-make/`).
예약 작업은 만들기 전에 이 예시들과 성적(저장·공유율), 그리고 **초안에서 사람이 고친 것**을 보고 `docs/reel-learned.md` 를 고친 뒤 그 기준으로 만든다.

## 흐름
1. 업로드 툴 → **릴스 만들기** → 스타일 · 원본 영상 · 권리 확인 · 글자 · 소리 고르기 → **자막 만들기**
   → `studio/작업이름/` 에 원본 + `job.json` 커밋 → `reel-studio.yml` (subs) 실행, 3~8분
2. 자막표에서 고치기 (시간·문장·강조) → **자막 저장하고 릴스 완성** → `reel-studio.yml` (render), 2~5분
3. 완성본 확인 → **이 영상으로 예약** → 새 게시물(릴스) 화면에서 날짜·캡션 넣고 예약
   → `queue/날짜_이름/reel.mp4` 로 옮기고 `studio/작업이름/` 은 통째로 지운다 (원본 정리)

- 해외 소스는 캡션 끝에 `🎥 영상: @원작자 (원작자 허락 받고 사용)` 줄이 자동으로 들어간다.
- 실패하거나 20분 넘게 멈추면 작업 화면에 **다시 시도** 버튼이 나온다. 원인은 GitHub → Actions → '맨티스 릴스 만들기' 로그.
- 저녁 점검(checks.py)이 7일 넘게 남은 작업과 저장소 용량(800MB 넘으면)을 알려준다.
- 저장소가 공개라서 처리 중인 원본은 잠시 공개 상태다. 예약하면 지워지지만 git 기록에는 남는다.

## 파일
- `publisher/reelmaker.py` — `subs` (Whisper + DeepL → subs.json), `render` (ffmpeg → reel.mp4)
- `.github/workflows/reel-studio.yml` — 업로드 툴이 실행 (inputs: job, step)
- `uploader/studio.js` — 릴스 만들기 탭
- `studio/작업이름/` — raw.mp4·voice.m4a(선택)·job.json·subs.json·status.json·reel.mp4
