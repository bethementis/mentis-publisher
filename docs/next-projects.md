## ① 맨티스 업로드 툴 (친구와 공유하는 웹 화면)

> **진행 상황 (2026-11-02):** A안으로 코드 완성 (`uploader/`, `worker/`, 워크플로 2개). 사용자 설정 대기 → [uploader-setup.md](uploader-setup.md)

### 왜
지금은 `queue/` 에 날짜 붙인 폴더를 직접 만들고 post.json 을 손으로 써야 해서 번거롭고, 친구와 같이 쓰기 어렵다.

### 하고 싶은 것
- 카드 이미지 드래그&드롭 (순서 바꾸기, 표지 지정, 4:5 아닌 카드 경고)
- 캡션 / 쓰레드 글 / 유튜브 제목 / 샤오홍슈 중국어 제목·본문·태그 입력 칸
- (선택) 중국어 카드 따로 업로드 (zh/)
- 발행 날짜를 **달력에서 선택** → 내부적으로 `queue/YYYY-MM-DD_이름/` 으로 커밋
- 예약 목록(캘린더/리스트), 수정·삭제·순서 변경
- 발행 결과 보기: published/*/result.json 의 플랫폼별 성공/실패/링크
- "지금 발행", "토큰 상태 확인(check)" 버튼 → workflow_dispatch
- 친구와 공유 가능 (링크 + 로그인)

| B. Claude 아티팩트 페이지 | claude.ai 에서 공유 링크 | 만들기 빠름 | 이미지를 GitHub 로 보내는 경로가 까다로움 |

### 구조 제안
1. **수집(프로그램, 무료):** GitHub Actions `metrics.yml` 매일 새벽 1회 → `metrics/YYYY-MM-DD.json`
   | 플랫폼 | 방법 | 필요 작업 |
   |---|---|---|
   | 인스타 | Graph API insights (reach, views, likes, comments, shares, saved, follows, profile_visits, online_followers) + comments + business_discovery(레퍼런스) | `instagram_manage_insights`, `instagram_manage_comments` 권한 확인/추가 |
   | 쓰레드 | Threads Insights API (views, likes, replies, reposts, quotes) + replies 조회 | `threads_manage_insights`, `threads_read_replies` 권한 확인/추가 |
   | 유튜브 | Data API(조회수/좋아요/댓글) + YouTube Analytics API | `yt-analytics.readonly` 스코프 추가 → refresh token 재발급 |
   | 틱톡 | Display API `video.list` | 샌드박스에 `video.list` 스코프 추가 후 재인증 |
   | 네이버 클립, 샤오홍슈 | API 없음 → 어사이드 루틴이 크리에이터 화면 숫자를 읽어 저장 | 정확도 낮음 |
2. **문제 알림:** 매일 수집 직후 점검 스크립트 실행 → 문제 있을 때만 알림 (GitHub 이슈 생성 + 사용자에게 알림)
3. **분석·보고(에이전트):** Claude 예약 작업(scheduled task) — 일간(매일 아침), 주간(월요일), 월간(1일).
   리포트는 사용자가 폰에서 보기 쉬운 형태(알림 + 리포트 문서/대시보드)로. 원자료는 metrics/*.json.

### 만드는 순서
1. 설계안 사용자 승인 → 권한 재발급 안내(사용자가 직접)
2. 수집 + 문제 알림 (인스타·쓰레드·유튜브 → 틱톡 → 네이버·샤오홍슈)
3. 일간 리포트 (댓글 답글 초안 포함)
4. 1~2주 데이터 쌓인 뒤 주간 리포트, 한 달 뒤 월간 리포트

### 주의
- 권한 추가는 각 플랫폼에서 사용자가 직접 재인증해야 함.
- 리포트에 확인 안 된 숫자를 지어내지 말 것. 수집 실패한 플랫폼은 "데이터 없음"으로 표시.
- 댓글 답글·DM은 자동 게시하지 않는다. 초안까지만, 게시는 사용자가 확인 후.
