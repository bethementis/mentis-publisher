# 세딸 릴스 자동 제작 설계 (승인 대기, 아직 안 만듦)

정한 날: 2026-11-10 (성현님과 정리). 근거: 11/6 회의 "덜 물어보는 자동화".

## 범위
- 만드는 릴스는 전부 **세딸** = 레퍼런스 보드 A 스타일 (해외 소스 · 세르칸, reel-styles.json 의 `overseas`).
- 매일 알아서 만드는 게 아니라, **영상함에 넣은 영상만** 만든다.
- 소스 원칙 그대로: 허락받은 영상·직촬·스톡만. 남의 영상 자동 내려받기 없음.

## 흐름
1. **영상함 (사람)**: 업로드 툴에 여러 개 한 번에 넣는다. 영상마다 원작자 계정·허락 메모는 꼭 적는다.
2. **제작 (Claude 1)**: 받아쓰기·번역 → 어색한 번역·자막 끊김 다듬기 → 훅 2개 → 완성본 → 썸네일 장면·멘트 → 캡션.
3. **채점 (Claude 2, 만든 쪽과 따로)**: 아래 채점표. 훅 2개 중 점수 높은 쪽으로.
4. **후보 (사람)**: 점수 순 카드 (미리보기·썸네일·점수·이유 한 줄·고치면 오를 점). '올리기' → 세딸로 바로 예약. 고치려면 기존 편집 화면.

## 제작 규칙
- **툴에 저장된 기본값**(templates/reel-presets.json 의 overseas: 글꼴·크기·위치·색·로고·썸네일 디자인)을 그대로 쓴다.
  단 배경 때문에 글자가 잘 안 보이면(대비 부족) 글자색·테두리 색을 바꾸거나 테두리·로고 굵기를 늘려도 된다.
- **원본에 영어 자막이 있으면 가리지 않고** 한국어 자막을 항상 그 바로 밑에 둔다 (Claude 가 장면을 보고 영어 자막 위치를 찾음).
- **코너 이름**(스킨케어 노트·바디 노트 등)은 릴스 화면에 넣지 않고 **썸네일에만**.
- **원작자 정보는 캡션에만** 쓴다. 릴스 화면에는 출처를 넣지 않는다.
- 썸네일 멘트는 **영상 주제와 맞는 것이 먼저** (예: "거북목, 12초면 펴져요"). 대상 좁히기를 억지로 끼우지 않는다.

## 채점표 (100점)
| 항목 | 점수 | 보는 것 |
|---|---|---|
| 조회 (터질까) | 40 | 첫 1초 훅이 스크롤을 멈추게 하나 / 끝까지 보게 하나 (궁금증과 회수, 길이) / 20~30대 남자 누구나 "내 얘기"인가 / 썸네일만 봐도 누르고 싶나 |
| 공유 (보낼까) | 30 | "이거 너 얘기다" 찔림·공감 / 친구 놀리기 좋은 포인트 / 말 걸 거리 (의외의 사실) |
| 저장 (다시 볼까) | 30 | 나중에 꺼내 볼 정보 (순서·주기·조합·제품) / 바로 따라 할 수 있나 |
| 감점 | − | 어색한 번역, 억지 문구, 자막 오류, 맨티스 정체 노출 |

점수는 예상치. 올린 뒤 모이는 저장·공유율(metrics)과 비교해서 채점표를 고쳐 간다.
