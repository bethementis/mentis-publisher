# 세딸 릴스 — 완성본에서 배운 것

성현님이 직접 확인하고 예약한 릴스(`queue|published/*/reel-make/`)에서 뽑은 기준. 세딸 자동 제작 예약 작업이 만들기 전에 읽고, 새 예시가 생기면 고친다.
30줄 이내. 줄마다 근거 폴더를 적는다. 예시가 1개뿐인 건 '(예시 1개)'로 표시하고 단정하지 않는다.

## 화면
- 로고: 가로형(심볼 옆에 MENTIS), 화면 아래쪽 y 1600, 너비 310, 진하기 0.9, 굵기 2, 남색(#0400e6). (예시 1개: 2026-11-10_거북목-교정)
- 위쪽 문구(훅): 영상 자체에 이미 글자(BEFORE/AFTER 등)가 있으면 비워 둔 적 있음. 화면이 이미 설명하면 훅을 넣지 않는 것도 선택지. (예시 1개: 거북목-교정)
- 출처는 화면에 안 넣음 (캡션에만).

## 썸네일
- 디자인 매거진, 프리텐다드, 글자 크기 125%, 로고는 MENTIS 글자만·흰색 85%·아래쪽. (예시 1개: 거북목-교정)
- 멘트는 주제 + 숫자 결과형: "거북목, *12분*이면 충분해요". 강조는 숫자 하나. (예시 1개: 거북목-교정)

## 캡션
- 첫 줄 = 무엇을 알려주는지 한 줄 ("휴지 한 롤로 자세 교정하는 법"). 그다음 문제 → 원인 → 방법 ①②③ 번호 → 주의 한 줄 → 저장 유도 CTA ("오늘 밤 자기 전에 따라 하려면 저장해둬.") → 해시태그 8개 안팎. (예시 1개: 거북목-교정)
- 출처 줄은 맨 끝에 `🎥 영상: @원작자` 만 (괄호 설명 없이). (거북목-교정)
- 말투: 담담한 반말 ("~다", "~해").
