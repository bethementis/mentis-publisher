# 멘티스 피드 메이커

카드뉴스 내용을 글로 적으면, 멘티스 피드와 같은 디자인·말투로 카드(슬라이드)와 캡션을 만들어 주는 도구입니다.

## 무엇으로 만들었나

- **웹페이지 한 장**(`index.html`)입니다. HTML·CSS·자바스크립트로 만들었고, 설치나 빌드가 없습니다.
- 바깥에서 불러오는 것:
  - 글꼴: Google Fonts(Noto Sans/Serif KR·JP·SC·TC, Playfair Display, Inter 등. 모두 무료 공개 글꼴)
  - 라이브러리: cdnjs의 html2canvas 1.4.1(카드를 PNG로 바꿈), JSZip 3.10.1(여러 장을 ZIP으로 묶음)
- AI 기능(스타일 분석, 피드 생성, 사진 설명·추천, 번역)과 저장 기능(스타일, 사진 라이브러리, 피드 보관함, 파일 저장)은 **claude.ai 아티팩트 실행 환경**(`window.claude`)을 씁니다.

## 실행 방법

### 1. claude.ai에서 쓰기 (모든 기능)
claude.ai에 아티팩트로 올린 페이지를 열면 모든 기능이 동작합니다. 처음 쓸 때 "Claude 사용", "파일 저장" 같은 권한을 묻는 창이 뜨면 허용하세요.

### 2. 내 컴퓨터 브라우저에서 열기 (미리보기만)
`index.html`을 크롬 등에서 열면 카드 디자인 미리보기, 글 수정, 사진 넣기, 드래그 편집, 되돌리기는 됩니다.
다만 아래 기능은 claude.ai 밖에서는 **동작하지 않습니다**. 화면에 안내 문구가 뜹니다.
- 스타일 분석, 피드 생성, 번역, 사진 설명·추천 (Claude 호출)
- 사진 라이브러리, 피드 보관함, 스타일 저장(클라우드)
- PNG/ZIP 저장 버튼

> 이 저장소의 자동 발행기처럼 claude.ai 없이 돌리려면, Claude API 키로 부르는 방식으로 바꾸는 작업이 따로 필요합니다. (지금은 비용 때문에 API를 쓰지 않는 방침)

## 사용 순서

1. **레퍼런스 분석**: 기존 피드를 게시물 단위로 최대 20개 넣고(캡션도 붙여넣기 가능) "스타일 분석하기"를 누르면 색·글꼴·번호·로고·표지 스타일·말투를 익힙니다.
2. **사진 라이브러리**: 쓸 사진을 넣어 두면 Claude가 설명을 달고, 피드를 만들 때 장마다 어울리는 사진을 추천합니다. 피드에 직접 넣은 사진도 자동으로 쌓입니다.
3. **새 피드 만들기**: 주제와 짧은 메모를 적고 "피드 만들기". 꼼꼼 모드는 기획 → 작성 → 검수 3단계로 만듭니다.
4. 장마다 글·사진·위치·크기를 고치고, 표지는 제목을 끌어 위치를, 모서리 동그라미로 크기를, 오른쪽 칸에서 색을 바꿉니다.
5. 필요하면 영어·일본어·중국어(간체/번체)로 번역합니다. 번역 뒤 원어민 검수를 한 번 더 거칩니다.
6. 저장 버튼으로 PNG/ZIP을 받습니다. 만든 피드는 "피드 보관함"에 자동 저장되어 나중에 다시 열 수 있습니다.

## 입력과 출력

### 입력
| 무엇 | 형식 |
|---|---|
| 레퍼런스 피드 | 카드 이미지(PNG/JPG), 피드당 최대 20장, 최대 20개 피드. 파일 이름 순서가 장 순서 |
| 새 피드 내용 | 주제 + 자유 메모(짧아도 됨). 숫자·통계는 출처와 함께 적은 것만 카드에 씀 |
| 사진 | PNG/JPG 등 이미지. 끌어다 놓기·붙여넣기(Ctrl+V) 가능 |
| 기존 표지 불러오기 | 완성된 표지 이미지 + 글자 없는 원본 사진 |
| 로고(선택) | 배경 투명 PNG, 600px 이하 |

### 출력
- **카드 크기**: 1080 × 1350px (4:5), PNG
- **파일 이름 규칙**
  - 한 장 저장: `주제_YYYYMMDD_NN.png` (예: `턱선_20261122_01.png`, 주제를 비워 두면 `feed_…`)
  - 전체 저장(ZIP): `주제_YYYYMMDD.zip` 안에 `01.png, 02.png, …` + `caption.txt`
  - 번역본을 보고 있을 때는 이름 뒤에 언어 코드가 붙음: `주제_YYYYMMDD_en.zip`
  - 모든 언어 한 번에: `주제_YYYYMMDD_all.zip` 안에 `ko/`, `en/`, `ja/`, `zh-CN/`, `zh-TW/` 폴더별로 `01.png…` + `caption.txt`
  - 스타일 파일: `mentis-style.json`

### 자동 발행기(`queue/`)에 넣을 때
발행기는 표지 파일 이름에 `cover`가 들어가야 맨 앞에 둡니다. ZIP을 풀어서
- `01.png` → `00_cover.png` 로 이름을 바꾸고,
- 캡션은 `caption.txt` 내용을 `post.json`의 `caption`에 붙여넣으세요.
- 샤오홍슈용 중국어 카드는 `zh-CN/` 폴더 이미지를 게시물 폴더의 `zh/` 에 넣으면 됩니다.

## 필요한 키

**없습니다.** 코드 안에 API 키·토큰·비밀번호가 들어 있지 않고, AI 기능은 claude.ai 계정으로 동작합니다. `.env.example` 은 나중에 키가 필요한 기능을 추가할 때 이름을 적어 두는 자리입니다. 실제 값은 저장소에 올리지 말고 `.env`(무시 목록에 있음)나 GitHub Secrets 에 넣으세요.

## 알아둘 점
- 저장소가 공개라서 결과 이미지(카드 PNG, ZIP), 사진, 개인 자료는 올리지 않습니다. `feedmaker/.gitignore` 가 막아 둡니다.
- 사진 라이브러리·피드 보관함 데이터는 claude.ai 계정 쪽에 저장되고, 이 저장소에는 올라가지 않습니다.
